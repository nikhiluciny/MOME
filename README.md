# MOME Demo Design

This repository contains the design prototypes for the MOME (Ministry of Mines and Energy) web application screens and modules.

## Directories & Modules

- **Home Page**: The main homepage landing screen design.
- **Project E-Application**: Multistep application process for projects (including production information, company information, and final review screens).
- **My Projects**: User project dashboard and project detail views.
- **Login Page** & **Registration Page**: User authentication pages.
- **My Profile**: User profile management screen.
- **Amend Permit**: Form/workflow to amend permits.
- **Fee Payment Page**: Payment gateway/checkout page mockup.
- **Help Center**: FAQs and support desk portal.
